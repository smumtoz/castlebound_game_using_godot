# Castlebound

Castlebound is a Godot game project. This repository contains the game source, assets, architecture diagram, and team contribution document.

## Run from source

1. Install Godot 4.6, the version listed in the project configuration.
2. In Godot's project manager, import `Project/project.godot`.
3. Open the project and run it with the editor's Play button (F5).

Godot will regenerate its local import and shader caches when the project opens.

## Project Contents

- `Project/`: Godot scenes, scripts, assets, UI elements, and export configuration.
- `Game_Architecture.png`: game architecture diagram.
- `Team Contribution Document.docx.pdf`: team contribution document.

The original submission also included an exported Windows executable (`Castlebound.exe`) and an archive of the build. These generated exports are excluded from this source repository. Use Godot's export tools and the included export configuration to create a new build.
